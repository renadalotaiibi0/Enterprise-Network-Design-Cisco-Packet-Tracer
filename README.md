# Enterprise Network Design – Cisco Packet Tracer

## Project Overview
Designed and simulated a network connecting two departments using Cisco Packet Tracer. The topology includes routers, switches, end devices, and servers for essential network services.

## Network Topology
![Network Topology](Screenshot%201448-05-30%20at%209.04.05%20PM.png)

## Network Components
- 2 Cisco 1841 Routers
- 2 Cisco 2960 Switches
- 4 Servers: DHCP, DNS, Web, and Email
- 4 PCs

## IP Addressing
| Network | Subnet |
|---|---|
| Department 1 | 192.168.1.0/26 |
| Department 2 | 192.168.3.0/25 |
| Router Link | 192.168.2.0/30 |

## Technologies
Cisco Packet Tracer, TCP/IP, Subnetting, DHCP, DNS, HTTP, Email Services, Routing and Switching.
